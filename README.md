# LinkedIn Algorithm 2026 — Claude Skill

A Claude Code skill that writes, rewrites, and audits LinkedIn posts for the 2026 algorithm — built around LinkedIn's 360Brew interest-graph model.

**Built by [Pruthvi Mehta](https://www.linkedin.com/in/pruthvimehta/)** — CA, content creator, and LinkedIn strategist with 70K+ followers.

---

## What It Does

This skill knows how the 2026 LinkedIn algorithm actually works — the 360Brew rebuild, the four-point coherence check, what gets rewarded (saves, dwell time, comment threads), and what gets penalized (AI-sounding language, engagement bait, external links in post body). It audits your draft, tells you exactly what the algorithm will like or flag, and rewrites the post in your natural voice.

Every output follows a structured format: Algorithm Read → Format Recommendation → Revised Post → Why This Works → CTA Options → Hashtag Suggestion.

---

## How to Trigger It

Say any of these in Claude Code:

- "Write a LinkedIn post about..."
- "Optimize this for LinkedIn"
- "Will this post perform?"
- "Review this LinkedIn draft"
- "Help me with LinkedIn content"
- "Improve my hook"
- Paste any LinkedIn draft and ask for feedback or a rewrite

---

## How to Install

1. Click on **`SKILL.md`** in this repo → click the **Raw** button → right-click anywhere on the page → **Save As** → save the file
2. On your Mac, open **Finder** → click **Go** in the menu bar → **Go to Folder** → type `~/.claude/skills/` → hit Enter
3. Create a new folder inside called `linkedin-algorithm-2026-general`
4. Move the downloaded `SKILL.md` file into that folder
5. Restart Claude Code

That's it. The skill is now active.

## How It Works

The skill contains a detailed breakdown of how LinkedIn's 360Brew model works in 2026 — the four-point coherence check (profile, network, engagement patterns, content), the four stages of distribution, what signals the algorithm rewards and penalizes, and a full audit + rewrite framework.

When triggered, Claude reads your draft against these rules, audits it, recommends a format (carousel, text-only, or text + photo), rewrites it in your voice, and gives you CTA options and hashtag suggestions.
